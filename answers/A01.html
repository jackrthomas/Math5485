Exercise 2. Taylor expansion

  1. Write down the degree \(n\) Taylor polynomial of \(f:\mathbb R \to \mathbb R\) about some point \(a\).

Answer.

\[\begin{align} T_nf(x) = \sum_{k=0}^n \frac {f^{(k)}(a)} {k!} (x-a)^k \nonumber \end{align}\]

  1. Write down your favourite form of the remainder \(R_n(x) := f(x) - T_nf(x)\)

Assuming \(f\) is sufficiently regular, we have:

Lagrange: There exists \(\xi = \xi(x)\) between \(x\) and \(a\) such that

\[\begin{align} R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!} (x-a)^{n+1}. \nonumber \end{align}\]

Cauchy: There exists \(\xi = \xi(x)\) between \(x\) and \(a\) such that

\[\begin{align} R_n(x) = \frac{f^{(n+1)}(\xi)}{n!} (x-\xi)^{n} (x-a). \nonumber \end{align}\]

Integral form:

\[\begin{align} R_n(x) = \int_a^x \frac{f^{(n+1)}(t)}{n!} (x-t)^{n} dt. \nonumber \end{align}\]

Peano:

\(R_n(x) = h_n(x) (x-a)^n\) for some function \(h_n\) satisfying \(\lim_{x\to a} h_n(x) = 0\) (this can also be written \(R_n(x) = o((x-a)^n)\) as \(x \to a\)).

Other answers are possible (but unlikely)

  1. Consider the function \(f(x) := \frac{e^x - 1}{x}\). Use Taylor expansion of \(e^x\) to evaluate \(\lim_{x\to 0} f(x)\).

Answer.

We have \(e^x = 1 + x + \frac{e^\xi}{2} x^2\) for some \(\xi\) between \(x\) and \(0\) and so

\[\begin{align} \left| f(x) - 1 \right| &= \left| \frac{1 + x + \tfrac{e^\xi}{2} x^2 - 1}{x} - 1 \right| \nonumber\\ % &\leq \frac{e^{\xi}}{2} |x|. \end{align}\]

As a result, \(\lim_{x\to0}f(x)=1\).

Exercise 3. Archimedes’ method for computing (lower bounds to) \(\pi\).

Recall that \(\pi\) is half the circumference of the unit circle. Let \(P_n\) be the inscribed regular \(n\)-gon inside the unit circle and notice that its perimeter satisfies \(2 \pi_n \leq 2 \pi\).

  • ✍️ Explain why \(\pi_n = n \sin \frac{\pi}{n}\),
  • 💻 What is the absolute error when approximating \(\pi\) with \(\pi_{2026}\)?
  • ✍️ Use Taylor expansion of \(\sin\) to explain why \((\pi_n)\) converges with rate \(O(n^{-2})\),
  • 💻 Verify this rate of convergence with a plot.
  • ✍️ For what \(n\) is \(\pi_n\) equal to \(\pi\) up to the first \(2026\) significant decimal digits?

Answer.

We can split the \(n\)-gon into \(n\) triangles by drawing lines from the centre of the unit circle to the vertices of \(n\)-gon. The angle at the centre of the circle is \(\frac{2\pi}{n}\) and thus the length of the opposite side is \(2 \sin \frac{\pi}{n}\). As a result, the perimeter of the \(n\)-gon is \(2 \pi_n = 2n \sin \frac{\pi}{n}\), as required.

Code 
πₙ(n) = n * sin( π/n )
println("abs. error is |π - π₂₀₂₆| = $(π-πₙ(2026))")
abs. error is |π - π₂₀₂₆| = 1.2589817468544595e-6

Using the Taylor expansion of \(\sin\) about \(0\) gives: there exists \(0 \leq \xi \leq x\) such that

\[\begin{align} \sin x &= \sin 0 + \cos(0) x - \frac12 \sin(0) x^2 - \frac16 \cos(\xi) x^3 \nonumber\\ % &= x - \frac16 \cos(\xi) x^3 . \end{align}\]

As a result, there exists \(0 \leq \xi \leq \frac{\pi}{n}\) such that

\[\begin{align} \left| \pi - \pi_n \right| &= \left| \pi - n \Big( \frac{\pi}{n} - \frac16 \cos(\xi) (\tfrac{\pi}{n})^3 \Big) \right| \nonumber\\ % &\leq \frac{\pi^3}{6} \frac1{n^2} \end{align}\]

Code 
nn = 2.0.^(1:15)
err = @. abs( π - πₙ(nn) )
plot( nn, err; 
    xaxis=:log, yaxis=:log, m=2, 
    xlabel=L"n", label=L"|\pi - \pi_n|" )
plot!( nn, nn.^(-2);
    linestyle=:dash, label=L"n^{-2}" )

We want \(n\) for which

\[\begin{align} \left|\frac{\pi - \pi_n}{\pi}\right| \leq 5 \times 10^{-2026}. \end{align}\]

The left hand side is bounded below by \(\frac{\pi^2}{6} \frac1{n^2}\). Therefore, to obtain the required bound, we can choose \(n \geq \frac{\pi}{\sqrt{30}} \times 10^{1013} \approx 5.7 \times 10^{1012}\).

Exercise 4. Subtractive Cancellation

Take \(f(x) := \frac{e^x - 1}{x}\). Implementing this function directly is a bad idea due to subtractive cancellation (we will go through this in detail in week 2). Julia has the built-in function expm1 which uses the Taylor expansion of \(e^x\) (as you did in Exercise 2) to evaluate \(e^x-1\) without subtractive cancellation.

Here are two ways of evaluating \(f(10^{-15})\):

Code 
g(x) = (exp(x)-1)/x    
h(x) = expm1(x)/x

g_x, h_x = g(1e-15), h(1e-15)
(1.1102230246251565, 1.0000000000000007)

What are the relative errors between the mathematical value of \(f(10^{-15})\) and the approximations g_x (naive formula) and h_x (Taylor expansion).

You may use y defined in the code below as the “exact” value of \(f(10^{-15})\) (which is correct to the first 100 significant digits).

Answer.

abs( (y-g_x)/y ), abs( (y-h_x)/y )
(0.11022302462515604, 2.220446049250312e-16)

By the above calculation, the function g gives an \(11\%\) error when approximating \(f(10^{-15})\) whereas the function h provides the correct result to machine precision.
