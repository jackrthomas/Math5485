8  Sample in-class test

Published

September 23, 2026

NAME:
STUDENT NUMBER:

Time allowed: 15 mins

Please label any paper you use with your name and student number

Electronic devices are not needed and not permitted in this test.

  1. [5 points] Let \(x_n = \frac{1 + n^2}{ 2 n^3 } \cos n\).
    For which of the following sequences \((\varepsilon_n)\) do we have \(x_n = O(\varepsilon_n)\) as \(n\to\infty\)?
    Please select all that apply.

\(\varepsilon_n = e^{-n}\)

\(\varepsilon_n = n^{-2}\)

\(\varepsilon_n = n^{-1}\)

\(\varepsilon_n = 1\)

\(\varepsilon_n = n\)

  1. [5 points] Recall that Float64 uses binary precision \(k = 52\). How many floating point numbers are in the interval \([64, 128)\)?
  1. [5 points] Let us define

\[\begin{align*} f(x) = \frac{\sqrt{1+x}-1}{x}, \qquad g(x) = \frac{1}{\sqrt{1+x} + 1}. \end{align*}\]

One may verify that \(f\) and \(g\) are mathematically identical (but you don’t have to). The following table is the output of evaluating \(f\) and \(g\) on \(\{10^{-14}, 10^{-15}, 10^{-16}\}\) in double precision floating point. Why are the function values different?

                         f(x)                  g(x)
x = 10^(-14):     0.4884981308350689    0.4999999999999988
x = 10^(-15):     0.44408920985006256   0.4999999999999999
x = 10^(-16):     0.0                   0.5
