    9.1 Previously…..

    • Barycentric formula: for \(x \not\in X\), \(I_Xf(x) = \sum_{j=0}^n \frac{\lambda_j f(x_j)}{x - x_j} \Big/ \sum_{j=0}^n \frac{\lambda_j}{x - x_j}\) where \(\lambda_j = \prod_{k\not=j} (x_j - x_k)^{-1}\),
    • Barycentric formula requires \(O(n)\) operations per evaluation and is numerically stable for Chebyshev nodes (with weights \((-1)^j\), halved for \(j = 0, n\)),
    • Divided differences: \(f[x_0,\dots,x_n]\) is the leading coefficient of \(I_Xf\); it doesn’t depend on the ordering of the nodes and is linear in \(f\),
    • Recursion: \(f[x_0,\dots,x_n] = \frac{f[x_1,\dots,x_n] - f[x_0,\dots,x_{n-1}]}{x_n - x_0}\) (Theorem 8.2),
    • Newton form: \(I_Xf = \sum_{k=0}^n f[x_0,\dots,x_k] \, \pi_k\) where \(\pi_k(x) = (x-x_0)\cdots(x-x_{k-1})\) (Theorem 8.3),
    • The coefficients can be read off from the divided difference table; adding a new node only adds one new term.

    9.2 Hermite Interpolation

    Now consider distinct nodes \(z_0, \dots, z_k\) with multiplicities \(m_0, \dots, m_k \geq 1\) and let \(X = \{\{ x_0, \dots, x_n \}\}\) be the multiset in which each \(z_j\) appears \(m_j\) times (so that \(n+1 = \sum_{j=0}^k m_j\)).

    Hermite: find \(p\) such that, for \(j = 0, \dots, k\),

    \[ \begin{align} p(z_j) &= f(z_j), \nonumber\\ p'(z_j) &= f'(z_j), \nonumber\\ &\vdots \nonumber\\ p^{(m_j-1)}(z_j) &= f^{(m_j-1)}(z_j). \end{align} \]

    Exercise 9.1 What is the least degree polynomial interpolant on \(X = \{\{x_0, x_0, \dots, x_0\}\}\) (where \(x_0\) is repeated \(n+1\) times)?

    Theorem 9.1 There exists a unique polynomial of degree at most \(n\) solving the Hermite interpolation problem.

    Proof. See Exercise 9.3.

    Again, we define the divided differences (but now for the more general case where we may have repeated interpolation nodes):

    Definition 9.1 We define the divided difference \(f[x_{0}, \dots, x_n]\) to be the leading coefficient in the polynomial interpolation \(p\in \mathcal P_n\) solving the Hermite interpolation problem for \(f\) on \(X\):

    \[ \begin{align} p(x) = f[x_0,\dots,x_n] x^n + q(x) \end{align} \]

    where \(q \in \mathcal P_{n-1}\) and \(p^{(l)}(z_j) = f^{(l)}(z_j)\) for \(l = 0,\dots,m_j-1\) and \(j = 0, \dots, k\).

    Theorem 9.2 Suppose that \(f\) is sufficiently differentiable (\(f \in C^{m-1}\) where \(m := \max_j m_j\)). Then, we have

    \[ \begin{align} f[x_0, \dots, x_n] &= \begin{cases} \frac{f^{(n)}(x_0)}{n!} & \text{if } x_0 = x_1 = \dots = x_n \\ \frac {f[x_1, \dots, x_n] - f[x_0, \dots, x_{n-1}]} {x_n - x_0} &\text{if } x_0 \not= x_n \end{cases} \end{align} \]

    If the nodes are not all equal, we can always reorder \(X\) so that \(x_0 \not= x_n\) (the divided difference does not depend on the ordering of the nodes).

    Proof. You have seen above that the Taylor polynomial

    \[ \begin{align} T_f(x) =\sum_{j=0}^n \frac{f^{(j)}(x_0)}{j!}(x - x_0)^j \end{align} \]

    solves the Hermite interpolation problem on \(X = \{\{x_0,\dots,x_n\}\}\) in the case where \(x_0 = \dots = x_n\). For such \(X\), the leading coefficient in this expression is \(f[x_{0}, \dots, x_n] = \frac{f^{(n)}(x_0)}{n!}\).

    For the second case, one can adapt the proof of Theorem 8.2 (see Exercise 9.4). \(\square\)

    9.3 Extra exercises

    Exercise 9.3 In this exercise, we prove Theorem 9.1. As in the notes, let \(z_0, \dots, z_k\) be distinct nodes with multiplicities \(m_0, \dots, m_k \geq 1\), and let \(n + 1 = \sum_{j=0}^k m_j\).

    1. Let \(r \in \mathcal P_n\) and suppose that \(r^{(l)}(z) = 0\) for \(l = 0, \dots, m-1\). Show that \(r(x) = (x - z)^m s(x)\) for some polynomial \(s\).
    2. Suppose that \(r \in \mathcal P_n\) satisfies \(r^{(l)}(z_j) = 0\) for all \(l = 0,\dots,m_j - 1\) and \(j = 0,\dots,k\). Show that \(r = 0\).
    3. Deduce that the Hermite interpolation problem has at most one solution in \(\mathcal P_n\).
    4. Consider the map \(L : \mathcal P_n \to \mathbb R^{n+1}\) defined by \(L p := \big( p^{(l)}(z_j) \big)_{j = 0,\dots,k, \; l = 0, \dots, m_j - 1}\). Show that \(L\) is linear and injective, and conclude that the Hermite interpolation problem has exactly one solution in \(\mathcal P_n\).

    For 1, write \(r\) as its Taylor polynomial about \(z\) (which is exact because \(r\) is a polynomial). For 2, apply 1 at \(z_0\) and then show that \(s\) still has zeros of order \(m_j\) at \(z_j\) for \(j \geq 1\). For 4, recall that an injective linear map between vector spaces of the same finite dimension is also surjective.

    1. Since \(r \in \mathcal P_n\), Taylor’s theorem is exact: \(r(x) = \sum_{l=0}^n \frac{r^{(l)}(z)}{l!} (x - z)^l = \sum_{l=m}^n \frac{r^{(l)}(z)}{l!} (x - z)^l = (x-z)^m s(x)\) where \(s(x) := \sum_{l=m}^n \frac{r^{(l)}(z)}{l!} (x - z)^{l-m}\).

    2. By 1, \(r(x) = (x - z_0)^{m_0} s_0(x)\). Fix \(j \geq 1\) and write \(u(x) := (x - z_0)^{m_0}\) (so that \(u(z_j) \not= 0\) because the nodes are distinct). By the Leibniz rule, \[ r^{(l)}(z_j) = \sum_{i=0}^l \binom{l}{i} u^{(l-i)}(z_j) \, s_0^{(i)}(z_j) = u(z_j) \, s_0^{(l)}(z_j) + \sum_{i=0}^{l-1} \binom{l}{i} u^{(l-i)}(z_j) \, s_0^{(i)}(z_j). \] By induction on \(l = 0, \dots, m_j - 1\), we obtain \(s_0^{(l)}(z_j) = 0\). Therefore, \(s_0\) satisfies the same conditions at \(z_1, \dots, z_k\) and, repeating the argument, we have \[ r(x) = (x - z_0)^{m_0} (x - z_1)^{m_1} \cdots (x - z_k)^{m_k} s(x) \] for some polynomial \(s\). If \(s \not= 0\), then \(r\) has degree at least \(\sum_j m_j = n+1\), which contradicts \(r \in \mathcal P_n\). Therefore \(s = 0\) and \(r = 0\).

    3. If \(p, q \in \mathcal P_n\) both solve the Hermite interpolation problem, then \(r := p - q \in \mathcal P_n\) satisfies \(r^{(l)}(z_j) = f^{(l)}(z_j) - f^{(l)}(z_j) = 0\) for all \(j\) and \(l = 0, \dots, m_j-1\). By 2, \(r = 0\) and so \(p = q\).

    4. Differentiation and evaluation are linear and so \(L\) is linear. If \(L p = 0\), then \(p = 0\) by 2, and so \(L\) is injective. Since \(\dim \mathcal P_n = n + 1 = \dim \mathbb R^{n+1}\), the rank-nullity theorem shows that \(L\) is also surjective. In particular, there exists \(p \in \mathcal P_n\) with \(L p = \big( f^{(l)}(z_j) \big)_{j,l}\), which is exactly a solution to the Hermite interpolation problem. By 3, this solution is unique.

    Exercise 9.4 In this exercise, we prove the second case of Theorem 9.2: if \(X = \{\{x_0, \dots, x_n\}\}\) is a multiset with \(x_0 \not= x_n\) and \(f\) is sufficiently differentiable, then \[ f[x_0, \dots, x_n] = \frac{f[x_1, \dots, x_n] - f[x_0, \dots, x_{n-1}]}{x_n - x_0}. \]

    1. Explain why the (Hermite) divided difference \(f[x_0,\dots,x_n]\) does not depend on the ordering of the nodes and why \((f + c g)[x_0,\dots,x_n] = f[x_0,\dots,x_n] + c\, g[x_0,\dots,x_n]\).
    2. Let \(p \in \mathcal P_{n-1}\) be the Hermite interpolant of \(f\) on \(X' := \{\{x_0, \dots, x_{n-1}\}\}\) and define \(g(x) := (x - x_n) f(x)\) and \(q(x) := (x - x_n) p(x)\). Show that \(q\) is the Hermite interpolant of \(g\) on \(X\).
    3. Deduce that \(\big( (x - x_n) f \big)[x_0, \dots, x_n] = f[x_0, \dots, x_{n-1}]\) and \(\big( (x - x_0) f \big)[x_0, \dots, x_n] = f[x_1, \dots, x_n]\).
    4. Conclude.

    For 2, use the product rule \(\frac{\mathrm d^l}{\mathrm dx^l} \big[ (x - a) u(x) \big] = (x - a) u^{(l)}(x) + l \, u^{(l-1)}(x)\) with \(u = p - f\). Treat the nodes \(z \not= x_n\) and the node \(z = x_n\) separately: if \(x_n\) appears \(m\) times in \(X'\), then it appears \(m+1\) times in \(X\). For 4, copy the end of the proof of Theorem 8.2.

    1. The Hermite interpolation problem (and therefore its unique solution, by Theorem 9.1) only depends on the multiset \(X\), not on how we label its elements. If \(p\) and \(q\) are the Hermite interpolants of \(f\) and \(g\), then \(p + c q \in \mathcal P_n\) satisfies \((p + cq)^{(l)}(z_j) = (f + cg)^{(l)}(z_j)\) for all the required \(j, l\), and so it is the Hermite interpolant of \(f + cg\). Comparing the coefficients of \(x^n\) gives linearity.

    2. Since \(q \in \mathcal P_n\), by Theorem 9.1 it is enough to show that \(q\) satisfies the Hermite conditions for \(g\) on \(X\). Let \(u := p - f\). By the product rule, \[ q^{(l)}(x) - g^{(l)}(x) = \frac{\mathrm d^l}{\mathrm dx^l} \big[ (x - x_n) u(x) \big] = (x - x_n) u^{(l)}(x) + l \, u^{(l-1)}(x) \] (where the second term is absent when \(l = 0\)). Let \(z\) be a node which appears \(m\) times in \(X'\) (so that \(u^{(i)}(z) = 0\) for \(i = 0, \dots, m-1\)).

    • If \(z \not= x_n\), then \(z\) also appears \(m\) times in \(X\). For \(l \leq m - 1\), we have \(u^{(l)}(z) = 0\) and \(u^{(l-1)}(z) = 0\) and so \(q^{(l)}(z) = g^{(l)}(z)\).
    • If \(z = x_n\), then \(z\) appears \(m + 1\) times in \(X\) (with \(m = 0\) if \(x_n \not\in X'\)). For \(l \leq m\), the first term vanishes because \(z - x_n = 0\), and the second term vanishes because \(l - 1 \leq m - 1\) (or \(l = 0\)). Therefore \(q^{(l)}(x_n) = g^{(l)}(x_n)\) for \(l = 0, \dots, m\).

    1. By 2, the leading coefficient (of \(x^n\)) of \(q\) is \(g[x_0,\dots,x_n]\). On the other hand, \(q(x) = (x - x_n) p(x)\) and the coefficient of \(x^{n-1}\) in \(p\) is \(f[x_0,\dots,x_{n-1}]\). Therefore, \(\big( (x - x_n) f \big)[x_0, \dots, x_n] = f[x_0, \dots, x_{n-1}]\). Applying this to the reordered multiset \(\{\{x_1, \dots, x_n, x_0\}\}\) (allowed by 1) gives \(\big( (x - x_0) f \big)[x_0, \dots, x_n] = f[x_1, \dots, x_n]\).

    2. Since \((x - x_0) f(x) - (x - x_n) f(x) = (x_n - x_0) f(x)\), linearity and 3 give \[ (x_n - x_0) f[x_0,\dots,x_n] = \big( (x - x_0) f \big)[x_0, \dots, x_n] - \big( (x - x_n) f \big)[x_0, \dots, x_n] = f[x_1, \dots, x_n] - f[x_0, \dots, x_{n-1}]. \] Dividing by \(x_n - x_0 \not= 0\) gives the result.
