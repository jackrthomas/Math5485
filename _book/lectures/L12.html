    12.1 Previously…..

    • Quadrature rules: \(\int_a^b f \approx \sum_j w_j f(x_j)\) with weights \(\{w_j\}\) and nodes \(\{x_j\}\),
    • Interpolatory rules: integrate the polynomial interpolant \(p(x) = \sum_{j=0}^n f(x_j) \ell_j(x)\) of \(f\) on \(X = \{x_0,\dots,x_n\}\), which gives the weights \(w_j = \int_a^b \ell_j(x) \mathrm{d}x\); when \(X\) is equispaced this is a Newton-Cotes rule,
    • Examples: rectangular rule \((b-a) f(a)\), midpoint rule \((b-a) f\big(\tfrac{a+b}{2}\big)\), trapezoid rule \(\frac{b-a}{2}\big( f(a) + f(b) \big)\), and Simpson’s rule \(\frac{b-a}{6}\big( f(a) + 4 f\big(\tfrac{a+b}{2}\big) + f(b) \big)\),
    • A rule is exact for all polynomials of degree \(N\) if \(\int_a^b p(x) \mathrm{d}x = \sum_j w_j p(x_j)\) for all \(p \in \mathcal P_N\); interpolatory rules on \(n+1\) nodes are exact on \(\mathcal P_n\) (rectangular & midpoint exact for degree \(0\), trapezoid degree \(1\), Simpson degree \(2\))
    • We also saw that, for \(n\) even and with nodes symmetric about \(\tfrac{a+b}2\), the rule is exact on \(\mathcal P_{n+1}\) (i.e. midpoint: degree \(1\), Simpson: degree \(3\)). Proof: \(\int_{a}^b (x-\frac{a+b}2)^{n+1} \mathrm{d}x = 0\) when \(n\) is even.
    • Error estimate: if the rule is exact on \(\mathcal P_N\), then use the error estimate for polynomial interpolation to obtain \[ \left| \int_a^b f - \sum_j w_j f(x_j) \right| \leq \frac{\|f^{(N+1)}\|_{L^\infty([a,b])}}{(N+1)!} \int_a^b |\ell_{\tilde X}(x)| \mathrm{d}x \] for a suitable set of nodes \(\tilde X \supseteq X\) with \(N+1\) elements,
    • Composite rules (apply the rule on each of \(K\) subintervals of length \(h = \frac{b-a}{K}\)) have errors: rectangular \(O(h)\), midpoint and trapezoid \(O(h^2)\), Simpson \(O(h^4)\).

    12.2 Gaussian quadrature

    Exercise 12.1

    By considering the change of variables \(y = \frac{2}{b-a} \left( x - \frac{a + b}{2} \right)\) and defining \(\tilde{f}(y) = \frac{b-a}{2} f\big( \tfrac{b-a}2 y + \tfrac{a+b}2 \big)\), show that

    \[ \begin{align} \int_a^b f(x) \mathrm{d}x = \int_{-1}^1 \tilde{f}(y) \mathrm{d}y. \end{align} \]

    Moreover, show that, if \(p\) is the polynomial interpolation of \(f\) on \(X \subset [a,b]\), then \(\tilde{p}\) is the polynomial interpolation of \(\tilde{f}\) on \(\tilde{X} \subset [-1,1]\) where \(\tilde{X} = \{ \frac{2}{b-a} \left( x - \frac{a + b}{2} \right) : x \in X \}\). As a result, we may without loss of generality consider the interval \([-1,1]\).

    Before: Fix \(X\) (equispaced gives Newton-Cotes rules) and find \(\{w_j\}\) such that the quadrature rule

    \[ \begin{align} \int_{-1}^{+1} f(x)\mathrm{d}x \approx \sum_{j=0}^n w_j f(x_j) \end{align} \]

    is exact on \(\mathcal P_N\) for maximal \(N\).

    Idea: Choose \(X\) and \(\{w_j\}\).

    Exercise 12.2

    Choose \(w_0, w_1\) and \(x_0, x_1\) such that

    \[ \begin{align} \int_{-1}^1 f \approx w_0 f(x_0) + w_1 f(x_1) \end{align} \]

    is exact for all polynomials of degree \(3 = 2n+1\).

    Integrate the functions \(f = 1, x, x^2, x^3\) and solve the resulting system of equations.

    Using the functions \(f = 1, x, x^2, x^3\), we want to solve

    \[ \begin{align} 2 &= w_0 + w_1 \nonumber \\ 0 &= w_0 x_0 + w_1 x_1 \nonumber \\ \frac{2}{3} &= w_0 x_0^2 + w_1 x_1^2 \nonumber \\ 0 &= w_0 x_0^3 + w_1 x_1^3 \nonumber \end{align} \]

    We have

    \[ \begin{align} 0 &= ( w_0 x_0 + w_1 x_1 )( x_0 + x_1 ) \nonumber \\ &= (w_0 x_0^2 + w_1 x_1^2) + ( w_0 + w_1 ) x_0 x_1 \nonumber \\ &= \frac23 + 2 x_0 x_1 \nonumber \end{align} \]

    and so \(x_0 x_1 = -\frac13\). Similarly, we have

    \[ \begin{align} \frac23 (x_0 + x_1) &= ( w_0 x_0^2 + w_1 x_1^2 )( x_0 + x_1 ) \nonumber \\ &= (w_0 x_0^3 + w_1 x_1^3) + ( w_0 x_0 + w_1 x_1 ) x_0 x_1 \nonumber \\ &= 0 + 0 \cdot x_0 x_1 = 0 \nonumber \end{align} \]

    and so \(x_0 = - x_1\) and \(x_0 = - \frac{1}{\sqrt{3}}\), \(x_1 = \frac{1}{\sqrt{3}}\).

    Finally, we have \(0 = w_0 x_0 + w_1 x_1 = (w_0 - w_1) x_0\) and so \(w_0 = w_1 = 1\).

    Exercise 12.2 gives the quadrature rule

    \[ \begin{align} \int_{-1}^1 f \approx f\big( -\tfrac{\sqrt3}{3} \big) + f\big( \tfrac{\sqrt3}{3} \big) \end{align} \]

    which is exact for all polynomials of degree \(\leq 3\). This is Gauss (or Gaussian) quadrature with \(n=1\).

    Exercise 12.3

    For \(n=1\), use the fact that Gauss quadrature is exact for all polynomials of degree \(2n+1 = 2(1) + 1 = 3\) to show that \[ \begin{align} \left| \int_{-1}^1 f(x) \mathrm{d}x - \left( f(-\tfrac{\sqrt3}{3}) + f(\tfrac{\sqrt3}{3}) \right) \right| % \leq \frac{1}{135} \max_{x\in [-1,1]} \big| f^{(4)}(x) \big|. \end{align} \]

    We have \(X = \{x_0, x_1\} = \{ -\frac{\sqrt3}{3}, \frac{\sqrt3}3 \}\).

    Choose \(p\) to be the Hermite interpolant on \(\{\{x_0,x_0, x_1,x_1\}\}\) (that is, \(p\in\mathcal P_3\) with \(p(x_j) = f(x_j)\) and \(p'(x_j) = f'(x_j)\) for \(j=0,1\)).

    Using the hint \(p = I_{\{\{x_0,x_0,x_1,x_1\}\}} f\), we have \[ \begin{align} &\left| \int_{-1}^1 f - \left( f(x_0) + f(x_1) \right) \right| \nonumber \\ % &= \left| \int_{-1}^1 f - \left( p(x_0) + p(x_1) \right) \right| \nonumber \\ % &= \left| \int_{-1}^1 (f - p) \right|. \nonumber \end{align} \] Here, we have used the fact that Gauss quadrature is exact for all polynomials of degree \(3\).

    Using the error estimate for Hermite interpolation, there exist \(\xi_x \in [-1,1]\) such that \(f(x) - p(x) = \frac{f^{(4)}(\xi_x)}{4!} (x-x_0)^2 (x-x_1)^2\). Therefore, \[ \begin{align} &\left| \int_{-1}^1 (f - p) \right| \nonumber \\ &\leq \frac1{4!} \|f^{(4)}\|_{L^\infty} % \int_{-1}^1 (x-x_0)^2 (x-x_1)^2 \mathrm{d}x \nonumber \\ &= \frac{8}{45} \frac{1}{4!} \| f^{(4)} \|_{L^\infty}\nonumber \\ &= \frac{1}{135} \| f^{(4)} \|_{L^\infty}, \nonumber \end{align} \] as required.

    Exercise 12.4

    Approximate \(\log 2 = \int_1^2 \frac{1}{x} \mathrm{d}x\) using Gauss quadrature and evaluate an upper bound for the error.

    First notice that \[ \begin{align} \log 2 &= \int_1^2 \frac1x \mathrm{d}x \nonumber \\ % &= \frac{1}{2} \int_{-1}^1 \frac1{ \frac{1}2 x + \frac32 } \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 \frac1{ 3 + x } \mathrm{d}x \nonumber \\ % &\approx \frac1{ 3 - \frac{\sqrt{3}}3 } + \frac1{ 3 + \frac{\sqrt{3}}3 } \nonumber \\ % &= \frac9{13}. \nonumber \end{align} \] The error here is \(\log 2 - \tfrac{9}{13} \approx 8.39 \times 10^{-4}\).

    The error bound is \(\frac{1}{135} \|f^{(4)}\|_{L^\infty}\) where \(f(x) = \frac{1}{3+x}\). Taking derivatives of \(f\), we find that \(f^{(4)}(x) = \frac{24}{(3+x)^5}\) and so the error between \(\log 2\) and the approximation using Gauss quadrature with \(n=1\) belongs to \[ \begin{align} &\big[\tfrac{24}{135} \min_{x\in [-1,1]} (3+x)^{-5}, \tfrac{24}{135} \max_{x\in [-1,1]} (3+x)^{-5}\big] \nonumber\\ % &= \big[ \tfrac1{5760}, \tfrac{1}{180} \big] % \approx \big[ 1.74 \times 10^{-4}, 5.56 \times 10^{-3} \big]. \end{align} \] The actual error belongs to this interval!

    Exercise 12.5

    Compare this to the rectangular rule and its composite rule with 2 sub-intervals, and the trapezoid and Simpson rules.

    Apply each rule to \(\int_1^2 g\) with \(g(x) = \frac1x\) (exact value \(\log 2 \approx 0.693147...\)):

    rule approximation error
    rectangular \(g(1) = 1\) \(-0.307\)
    composite rectangular, \(K = 2\) \(\frac12\big( g(1) + g(\frac32) \big) = \frac56\) \(-0.140\)
    trapezoid \(\frac12 \big( g(1) + g(2) \big) = \frac34\) \(-0.0569\)
    Simpson \(\frac16\big( g(1) + 4 g(\frac32) + g(2) \big) = \frac{25}{36}\) \(-1.30 \times 10^{-3}\)
    Gauss, \(n = 1\) \(\frac{9}{13}\) \(8.39 \times 10^{-4}\)

    Using the error estimates from last time (with \(g''(x) = 2x^{-3}\) and \(g^{(4)}(x) = 24 x^{-5}\) on \([1,2]\)), the trapezoid error is \(-\frac{(b-a)^3}{12} g''(\xi) \in [-\frac16, -\frac1{48}]\) and the Simpson error is \(-\frac{(b-a)^5}{2880} g^{(4)}(\xi) \in [-\frac1{120}, -\frac1{3840}]\); the actual errors lie in these intervals.

    Gaussian quadrature uses only two function values and beats the trapezoid rule (also two function values, but only exact on \(\mathcal P_1\)) by a factor of about \(70\). It is even slightly more accurate than Simpson’s rule, which is also exact on \(\mathcal P_3\) but needs three function values.

    Question: How to generalise this?

    Answer: It turns out that one can choose the interpolation nodes and weights so that the quadrature rule

    \[ \begin{align} \int_{-1}^1 f(x) \mathrm{d}x \approx \sum_{j=0}^n w_j f(x_j) \end{align} \]

    is exact for all polynomials of degree \(2n+1\). The solution in the general case involves a set of orthogonal polynomials:

    12.3 Legendre polynomials

    In the following, we will write \[ (f,g)_{L^2} := (f,g)_{L^2([-1,1])} := \int_{-1}^{+1} f(x) g(x) \mathrm{d}x \] for the \(L^2\) inner product and \(\|f\|_{L^2}\) for the corresponding norm: \[ \begin{align} \|f\|_{L^2} := \left( \int_{-1}^1 |f(x)|^2 \mathrm{d}x \right)^{1/2}. \end{align} \]

    (This generalises the same definitions for vectors \(x, y \in \mathbb R^d\) with the Euclidean inner product (or dot product) defined by \((x,y) := x \cdot y = x^\top y = \sum_i x_i y_i\) and Euclidean norm \(|x| = \sqrt{\sum_{i} |x_i|^2}\)).

    Definition 12.1 We say that \(f\) is orthogonal to \(g\) with respect to the inner product \((\,\cdot\,,\,\cdot\,)\) if \((f,g)_{L^2} = 0\).

    Definition 12.2 Let the Legendre polynomial \(P_n\) be the monic polynomial of degree \(n\) such that \((P_n, q)_{L^2([-1,1])} = 0\) for all \(q \in \mathcal P_{n-1}\).

    Equivalently, \(\{P_n\}\) is defined as the sequence of monic polynomials with \((P_n, P_m)_{L^2} = 0\) for all \(n \not= m\) (see Exercise 12.7).

    It may not be immediately clear that such polynomials exist, but we can compute the first few explicitly:

    Exercise 12.6

    Show that \(P_0(x) = 1\), \(P_1(x) = x\), and \(P_2(x) = x^2 - \frac13\). What are the roots of \(P_2\) and compare to the nodes in Exercise 12.2.

    Write \(P_0(x) = 1\), \(P_1(x) = x + a\), and \(P_2(x) = x^2 + b x + c\) and solve for \(a, b, c\).

    When \(n=0\), there is only one monic polynomial: \(P_0(x) = 1\).

    When \(n=1\), we require \(P_1(x) = x + a\) to satisfy

    \[ \begin{align} 0 = \int_{-1}^1 P_1(x) \cdot 1 \, \mathrm{d}x = 2 a \end{align} \]

    and so \(P_1(x) = x\).

    When \(n=2\), we have \(P_2(x) = x^2 + a x + b\) and so

    \[ \begin{align} 0 &= \int_{-1}^1 P_2(x) \cdot 1 \, \mathrm{d}x = 2b + \frac23 \nonumber \\ 0 &= \int_{-1}^1 P_2(x) x \, \mathrm{d}x = \frac{2a}3 \nonumber \end{align} \]

    therefore \(P_2(x) = x^2 - \frac13\).

    Theorem 12.1 The Legendre polynomials exist for all \(n\).

    Proof. Let \(p_0 = 1\) and \(p_1 = x\).

    If \(p_0, p_1, \dots, p_n\) have been defined, we define

    \[ \begin{align} a_n &:= \frac{ \int_{-1}^1 x p_{n}(x)^2 \mathrm{d}x }{\|p_{n}\|_{L^2}^2} \qquad \text{and} \nonumber \\ b_{n} &:= \frac{ \int_{-1}^1 x p_{n}(x) p_{n-1}(x) \mathrm{d}x }{\|p_{n-1}\|_{L^2}^2} \nonumber \end{align} \]

    and thus \(p_{n+1}(x) := (x - a_n) p_n(x) - b_n p_{n-1}(x)\) for all \(n \geq 1\).

    We claim that \(p_n(x)\) is the \(n^\text{th}\) Legendre polynomial. We prove this by induction: the statement is true for \(n=0\) and \(n=1\). Suppose the statement is true for \(p_0, p_1, \dots, p_n\).

    Then, notice that \(p_{n+1}(x)\) is a monic polynomial of degree \(n+1\).

    Moreover, we have: for all \(j < n-1\),

    \[ \begin{align} \int_{-1}^1 p_{n+1}(x) p_{j}(x) \mathrm{d}x % &= \int_{-1}^1 \left[ (x - a_n) p_{n}(x) - b_n p_{n-1}(x) \right] p_j(x) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 p_{n}(x) \left[ (x - a_n) p_j(x) \right] \mathrm{d}x - b_n \int_{-1}^1 p_{n-1}(x) p_j(x) \mathrm{d}x \nonumber \\ % &= 0. \nonumber \end{align} \]

    Here, we have used the fact that \((x-a_n) p_j\) is a polynomial of degree \(j+1 < n\), \(p_j\) is a polynomial of degree \(j < n-1\), and \(p_n\), \(p_{n-1}\) are the \(n^\text{th}\) and \((n-1)^\text{th}\) Legendre polynomials.

    Moreover, we have

    \[ \begin{align} \int_{-1}^1 p_{n+1}(x) p_{n-1}(x) \mathrm{d}x % &= \int_{-1}^1 \left[ (x - a_n) p_{n}(x) - b_n p_{n-1}(x) \right] p_{n-1}(x) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 x p_{n}(x) p_{n-1}(x) \mathrm{d}x - b_n \int_{-1}^1 | p_{n-1}(x) |^2 \mathrm{d}x \nonumber \\ % &= 0 \nonumber \end{align} \]

    and

    \[ \begin{align} \int_{-1}^1 p_{n+1}(x) p_{n}(x) \mathrm{d}x % &= \int_{-1}^1 \left[ (x - a_n) p_{n}(x) - b_n p_{n-1}(x) \right] p_{n}(x) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 (x - a_n) p_{n}(x)^2 \mathrm{d}x \nonumber \\ % &= 0. \nonumber \end{align} \]

    As a result, \(p_{n+1}\) is monic and orthogonal to all polynomials of degree \(\leq n\).

    Remark 12.1. The roots of \(P_2\) are \(\{ -\tfrac{\sqrt3}{3}, \tfrac{\sqrt3}{3} \}\) (which are the nodes used in the quadrature rule of Exercise 12.2).

    Recall \(P_n\) are the Legendre polynomials and define the set of Legendre points \(X\) by

    \[ \begin{align} X := \{ \text{zeros of } P_{n+1} \}. \end{align} \tag{12.1}\]

    Lemma 12.1 \(X\) given by (12.1) is a set of \(n+1\) distinct points in \([-1,1]\).

    Proof. Notice that \(P_{n+1}(x) = \prod_{j=0}^n(x-x_j)\) (i.e. the monic polynomial with roots \(X\)). Here, we assume that the roots \(x_j\) are real (see Exercise 12.10 for an argument which also shows this).

    Suppose that \(x_0 = x_1\) and define \(q(x) := \prod_{j=2}^n (x - x_j)\). Then, since \(P_{n+1}\) is orthogonal to \(q\) (as \(q\) is of degree \(n-1\)), we have

    \[ \begin{align} 0 &= \int_{-1}^1 P_{n+1}(x) q(x) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 \left(\prod_{j=0}^n (x - x_j) \right) \left( \prod_{j=2}^n (x - x_j) \right) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 (x - x_0)^2 \prod_{j=2}^n (x - x_j)^2 \mathrm{d}x >0, \nonumber \end{align} \]

    a contradiction (the integral of a non-negative polynomial, which is not identically zero, over an interval of positive length is positive). By relabeling the indices in \(X = \{x_0,\dots,x_n\}\), we see that \(X\) is a set of pairwise distinct nodes.

    Suppose \(x_k \not\in [-1,1]\). Then, on defining \(q(x) := \prod_{\substack{0\leq j\leq n : \\ j \not= k }} (x - x_j)\), a polynomial of degree \(n\), we have

    \[ \begin{align} 0 &= \int_{-1}^1 P_{n+1}(x) q(x) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 \left(\prod_{j=0}^n (x - x_j) \right) \left( \prod_{j\not=k} (x - x_j) \right) \mathrm{d}x \nonumber \\ % &= \int_{-1}^1 (x - x_k) \prod_{j\not=k} (x - x_j)^2 \mathrm{d}x. \nonumber \end{align} \]

    Now, since \(x_k \not\in [-1,1]\), we have \((x - x_k)\) is either strictly positive or strictly negative for \(x \in [-1,1]\). Therefore, \(\int_{-1}^1 (x - x_k) \prod_{j\not=k} (x - x_j)^2\mathrm{d}x\) is either strictly positive or strictly negative, a contradiction. As a result, each \(x_k\) is in the interval \([-1,1]\).

    Definition 12.3 (Gaussian quadrature) Let \(p\) be the polynomial interpolation of \(f\) on the \(n+1\) Legendre points. Then, we may define the quadrature rule

    \[ \begin{align} \int_{-1}^1 f(x) \mathrm{d}x \approx \int_{-1}^{1} p(x) \mathrm{d}x = \sum_{j=0}^n w_j f(x_j) \end{align} \]

    where \(w_j = \int_{-1}^1 \ell_j(x) \mathrm{d}x\) and \(\ell_j\) are the Lagrange polynomials for the interpolation set (12.1).

    Theorem 12.2 Gaussian quadrature is exact for polynomials of degree \(2n+1\).

    Proof. First, note that we have already seen that Gaussian quadrature is exact for all polynomials of degree \(n\).

    Let \(X = \{x_0,\dots,x_n\}\) be the zeros of \(P_{n+1}\), \(w_j\) the corresponding quadrature weights, and let \(P\) be a polynomial of degree \(2n+1\). On dividing \(P\) by \(P_{n+1}\), there exist \(q_n, r_n \in \mathcal P_n\) such that

    \[ \begin{align} P(x) = P_{n+1}(x) q_n(x) + r_n(x). \end{align} \]

    Notice that \(P(x_j) = P_{n+1}(x_j) q_n(x_j) + r_n(x_j) = r_n(x_j)\) so that \(r_n\) is a degree \(n\) polynomial interpolant of \(P\) on \(X\). Using this, combined with the fact that \(P_{n+1}\) is orthogonal to \(q_n\), we have

    \[ \begin{align} \int_{-1}^1 P &= \int_{-1}^{1} \left[ P_{n+1}(x) q_n(x) + r_n(x) \right] \mathrm{d}x \nonumber \\ &= 0 + \int_{-1}^{1} r_n(x) \mathrm{d}x \nonumber \\ % &= \sum_{j=0}^n w_j r_n(x_j) \nonumber \\ % &= \sum_{j=0}^n w_j P(x_j). \nonumber \end{align} \]

    Therefore, Gaussian quadrature is exact for all polynomials of degree \(\leq 2n+1\).

    Lemma 12.2 The Gaussian quadrature weights satisfy

    • \(\sum_{j=0}^n w_j = 2\),
    • \(w_j > 0\) for all \(j\).

    Proof. Notice that \(\sum_{k=0}^n \ell_k(x)\) is a polynomial of degree \(n\) which is equal to \(1\) on the set of \(n+1\) points \(X\) and so \(\sum_{k=0}^n \ell_k(x)= 1\) for all \(x\). Therefore, because the quadrature rule is exact for polynomials of degree \(2n+1\), we have

    \[ \begin{align} 2 &= \int_{-1}^1 \mathrm{d}x \nonumber \\ &= \int_{-1}^1 \sum_{k=0}^n \ell_k(x) \mathrm{d}x \nonumber \\ &= \sum_{j=0}^n w_j \left[ \sum_{k=0}^n \ell_k(x_j) \right] \nonumber \\ &= \sum_{j=0}^n w_j. \nonumber \end{align} \]

    Moreover, \(\ell_k(x)^2\) is a polynomial of degree \(2n\) and the quadrature rule is exact for all polynomials of degree \(2n +1\), so we have

    \[ \begin{align} 0 &< \int_{-1}^1 \ell_k(x)^2 \mathrm{d}x \nonumber \\ &= \sum_j w_j \left[ \ell_k(x_j)^2 \right] \nonumber \\ &= w_k. \nonumber \end{align} \]

    Therefore, the weights are positive and sum to \(2 = \int_{-1}^1 1 \mathrm{d}x\).

    We may use a recursion of this form to compute the Legendre polynomials (the code below uses the standard normalisation \(P_n(1) = 1\) rather than monic polynomials, which does not change the roots): here we plot \(P_n\) for \(n \leq 8\) and the set of Legendre points for \(n = 8\).

    Next we approximate the integral

    \[ \begin{align} \int_{-1}^{+1} \frac{1}{1 + e^{10(x - 0.5)}} \mathrm{d}x \end{align} \]

    by using (i) the composite trapezoid rule, (ii) the composite Simpson rule (from last time) and (iii) Gaussian quadrature.

    One way to see exponential convergence comes from the following error estimate. Let \((w_j, x_j)_{j=0}^{n+1}\) be the weights and nodes from Gaussian quadrature and let \(I_Xf\) be the polynomial interpolation of \(f\) on \(X = \{x_j\}_{j=0}^n\). Then, because \(\int_{-1}^{+1} P_{2n+1} = \sum_{j=0}^n w_j P_{2n+1}\) for all polynomials \(P_{2n+1}\) of degree \(2n+1\), we have \[ \begin{align} &\Big|\int_{-1}^{+1} f(x) \mathrm{d}x - \sum_{j=0}^n w_j f(x_j)\Big| \nonumber\\ % &\leq \Big|\int_{-1}^{+1} \left( f(x) - P_{2n+1}(x) \right) \mathrm{d}x\Big| % + \Big|\sum_{j=0}^n w_j \left( f(x_j) - P_{2n+1}(x_j) \right) \Big| \nonumber\\ % &\leq 4 \max_{x\in [-1,1]}| f(x) - P_{2n+1}(x) | =: 4 \|f-P_{2n+1}\|_{L^\infty}. \end{align} \] Here, we have used the fact that \(|\int_{-1}^{+1} g| \leq 2 \|g\|_{L^\infty}\) and \(|\sum_{j=0}^n w_j g(x_j)| \leq \sum_{j=0}^n |w_j| |g(x_j)| \leq 2 \|g\|_{L^\infty}\) (because the weights are positive and sum to \(2\)). We obtain the error estimates as seen in the plot above by showing that polynomial approximations to \(f(x) = (1 + e^{10(x-\tfrac12)})^{-1}\) on \([-1,1]\) converge exponentially as \(n\to\infty\); a possible presentation topic. (We may also return to this in Chapter 6: Approximation theory, time permitting).
