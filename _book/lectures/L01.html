    1.6 Chapter 1: Basics of Numerical Analysis

    • Absolute and relative error
    • Rate of convergence
    • Using plots to show rate of convergence

    Suppose we approximate \(x\) with \(\widetilde{x}\). Here, \(x\) could be e.g. a root (or fixed point) of a function, the value of an integral, the solution of an ODE or PDE evaluated at a point, …. .

    Definition 1.1 (Errors) We define:

    \[\begin{align} \text{Actual error:} &\quad x - \widetilde{x} \\ \text{Absolute error:} &\quad |x - \widetilde{x}| \end{align}\]

    And when \(x \neq 0\), the relative error is:

    \[\begin{align} \text{Relative error:} \quad \frac{|x - \widetilde{x}|}{|x|} \end{align}\]

    Example 1.1 If \(x = 1.5\) and \(\widetilde{x} = 1\), then the absolute error is \(0.5\) and the relative error is \(\frac{0.5}{1.5} = \frac13\).

    If \(x = 1.5 \times 10^{42}\) and \(\widetilde{x} = 10^{42}\), then the absolute error is \(0.5 \times 10^{42}\) and the relative error is \(\frac13\).

    If \(x = 1.5 \times 10^{-42}\) and \(\widetilde{x} = 10^{-42}\), then the absolute error is \(0.5 \times 10^{-42}\) and the relative error is \(\frac13\).

    The relative error is a better measure for small or large \(x\):

    Example 1.2 Approximating Planck’s constant \(6.62607015 \times 10^{-34} \text{m}^2 \text{kg } \text{s}^{-1}\) with \(0 \text{m}^2 \text{kg } \text{s}^{-1}\) would give an absolute error of \(\approx 6 \times 10^{-34}\) (which seems small) but a relative error of \(1\). In practice \(0\) is a bad approximation to Planck’s constant!

    Definition 1.2 (Number of correct significant digits) Suppose \(x \not= 0\) is approximated by \(\widetilde{x}\). Then, we say this approximation is accurate to \(n\) significant digits if

    \[\left| \frac{x-\widetilde{x}}{x} \right| \leq 5 \times 10^{-n}.\]

    Example 1.3 Approximating \(e := \lim_{n\to\infty} \big( 1 + \frac1n \big)^n \approx 2.7182818.....\) with \(3, 2.7,\) and \(2.718\) gives

    \[\begin{align} \left| \frac{e-\widetilde{x}}{e} \right| = 1.04 \times 10^{-1}, \quad 0.673 \times 10^{-2}, \quad 0.104 \times 10^{-3}, \end{align}\]

    respectively.

    Code 
    e = exp(1)
abs( (e-3)/e ), abs( (e-2.7)/e ), abs( (e-2.718)/e )
    (0.10363832351432703, 0.006725508837105614, 0.00010367889601972718)

    Remark 1.1 (Number of correct significant digits). Suppose \(x \not= 0\) is approximated by \(\widetilde{x}\). Some people say that this approximation is accurate to

    \[\eta := - \log_{10} \left| \frac{x-\widetilde{x}}{x} \right|\]

    significant digits.

    Exercise 1.2

    Compute \(\eta\) for approximating \(e\) with \(3\), \(2.7\), and \(2.718\).

    We have

    Code 
    η( x, x_tilde ) = - log10( abs(x-x_tilde)/abs(x) )
η( exp(1), 3 ), η( exp(1), 2.7 ), η( exp(1), 2.718 )
    (0.9844796209116626, 2.172274852323722, 3.984309635847452)

    We now consider a sequence of approximations \(x_n\) converging to \(x\). That is, for all \(\varepsilon > 0\), there exists \(N=N(\varepsilon)\) such that \(|x - x_n| < \varepsilon\) for all \(n > N\). In numerical analysis, we are interested in (i) whether our numerical schemes converge, and (ii) the rate of convergence:

    Definition 1.3 (Rate of convergence) Suppose \(\varepsilon_n \geq 0\) and \((\varepsilon_n) \to 0\). Then, \(x_n \to x\) with rate \(O(\varepsilon_n)\) if there exist \(C\) and \(N\) such that

    \[ |x - x_n| \leq C\varepsilon_n \]

    for all \(n > N\). We also write \(x_n = x + O(\varepsilon_n)\).

    Exercise 1.3

    Show that \(\frac{n + \cos(n)}{n^2} = O(\frac1n)\) and \(\frac{n^2+3}{n^{42}} = O(\frac1{n^{40}})\).

    Since \(\cos(n) \leq n\) for all \(n \in \mathbb{N}\), we have

    \[\begin{align} \frac{n + \cos n}{n^2} % \leq \frac{2n}{n^2} = \frac{2}{n}. \end{align}\]

    That is, \(\frac{n + \cos n}{n^2}\) is bounded above by a constant multiple of \(n^{-1}\) so \(\frac{n + \cos n}{n^2} = O(n^{-1})\).

    Similarly, \(3 \leq 3n^2\) so \(\frac{n^2 + 3}{n^{42}} \leq \frac{4}{n^{40}}\).

    When plotting graphs, \(O(n^{-k})\) decay (that is, algebraic decay) can be seen as straight lines on log-log plots (\(-k\) is the slope in such graphs):

    Code 
    N = 1:100;
plot( N.^(-1) ;
    xlabel="n", xaxis=:log, yaxis=:log, 
    linestyle = :dot, lw=2, label = L"n^{-1}")
plot!( N.^(-2); 
    linestyle = :dot, lw=2, label = L"n^{-2}")
plot!( N.^(-5); 
    linestyle = :dot, lw=2, label = L"n^{-5}")

    On the other hand, \(O(e^{-c N})\) (that is, exponential decay) can be seen as straight lines on a semi-log y plot (and \(-c\) is the gradient):

    Code 
    plot( exp.(-N);
    xlabel="n", yaxis=:log, 
    linestyle = :dot, lw=2, label = L"e^{-n}")
plot!( exp.(-2 .* N ); 
    linestyle = :dot, lw=2, label = L"e^{-2n}")
plot!( exp.(-5 .* N ); 
    linestyle = :dot, lw=2, label = L"e^{-5n}")

    Exercise 1.5

    Euler-Mascheroni constant, \(\gamma\), is defined as the limit of \(\gamma_n = \sum_{k=1}^n \frac{1}{k} - \log n\) as \(n \to \infty\).

    1. What is the absolute error in approximating \(\gamma\) with \(\gamma_{1000}\)?
    2. What is the rate of convergence of \(\gamma_n\) to \(\gamma\)?
    3. [This was just so that we can remember some calculus and also rigorously prove the rate of convergence that we have seen above using a rigorous error estimate]
      Prove that \(|\gamma - \gamma_n| \leq \frac1n\).

    First, we define the Euler-Mascheroni constant:

    Code 
    γ = Base.MathConstants.eulergamma
    γ = 0.5772156649015...

    … and compute the absolute error in approximating \(\gamma\) with \(\gamma_{1000}\):

    Code 
    Nmax = 1000;

N = 1:Nmax;
γN = zeros( Nmax );
γN[1] = 1;
for n ∈ 2:Nmax
    γN[n] = (1/n) + γN[n-1] + log( (n-1)/n );
end

println( "γ₁₀₀₀ = ", γN[1000] )
println( "Abs. error = " , abs( γ - γN[1000] ) )
    γ₁₀₀₀ = 0.5777155815682078
Abs. error = 0.0004999166666749266

    Here’s a plot of the absolute errors on a log-log; the gradient matches \(O(N^{-1})\):

    Code 
    plot( γN .- γ , xaxis=:log, yaxis=:log , legend = false, lw = 2, m=2)   
plot!( N.^(-1) , linestyle=:dash)

    Proof. First, notice that

    \[\begin{align} \gamma_n - \gamma_N % &= \log \frac Nn - \sum_{k=n+1}^N \frac{1}{k}\\ % &= \sum_{k=n+1}^N \left( \log \frac{k}{k-1} - \frac{1}{k} \right). \end{align}\]

    Here, \(\frac1k\) is the area under the rectangle with base \([k-1,k]\) and height \(\frac1k\) and \(\log \frac{k}{k-1}\) is the integral of \(\frac1x\) between \(x = k-1\) and \(x = k\):

    Code 
    k=3; x = range(k-1,k, 100);
plot( x, [x.^(-1) ones(100)./k (x .+ 1).^(-1)], 
    ylims=(0,1/(k-1)), 
    label=[L"y=\frac{1}{x}" L"\frac{1}{k}" L"y=\frac{1}{x+1}"] )

    In the graph above, \(\frac1k\) is the area under the red line, \(\log \frac{k}{k-1}\) is the area under the blue line. We upper bound the absolute value of the error between these areas, by computing the area between \(y = \frac1x\) and \(y=\frac1{x+1}\):

    \[\begin{align} 0 \leq \gamma_n - \gamma_N % &\leq \sum_{k=n+1}^N \left( \log \frac{k}{k-1} - \frac{1}{k} \right) \\ % &\leq \sum_{k=n+1}^N \int_{k-1}^k \left( \frac{1}{x} - \frac{1}{x + 1} \right) \mathrm{d}x % = \int_{n}^\infty \frac{1}{x(x+1)} \mathrm{d}x \\ % &\leq \int_{n}^\infty \frac{1}{x^2} \mathrm{d}x = \frac1n \end{align}\]

    Here, we have shown that \((\gamma_n)\) is a Cauchy sequence and thus it converges, and we have the same estimate for \(\gamma_n - \gamma\) by taking the limit in \(N\). \(\text{ }\square\)

    Exercise 1.6

    Assignment 1, Fall 2025, 30 pts The quantities

    \[\begin{align} \pi_N := 4 \sum_{n=0}^N \frac{(-1)^n}{2n+1} \end{align}\]

    approximate \(\pi\) by using the Taylor expansion of \(\arctan\) together with the fact that \(\pi = 4 \arctan(1)\).

    Code 
    using Plots, LaTeXStrings

Nmax = 100;
Ninter = 1:Nmax;

# vectors of length Nmax
p = zeros( Nmax ); q = zeros( Nmax );
p[1] = 4 * ( 1 - 1/3 ) ;
q[1] = abs( p[1] - π );
for N in 2:Nmax
    p[N] = p[N-1] + 4 * (-1)^N/(2*N + 1);
    q[N] = abs( p[N] - π );
end

plot(p, legend=false, xlabel="N", title=L"\pi_N")

    Based on the following graph, what is the rate of convergence of this particular approximation to \(\pi\)? Why do we use a log-log scale for this graph?

    Code 
    plot( q , xaxis=:log, yaxis=:log, xlabel=L"N", title="absolute error", legend=false)
plot!( Ninter.^(-1) , ls=:dash)

    We have \(|\pi - \pi_N| = O(N^{-1})\). The log-log plot makes this behaviour easy to see.

    In fact, one can show that

    \[\begin{align} |\pi - \pi_N| &= 4 \int_{0}^1 \frac{t^{2(N+1)}}{1 + t^2} \mathrm{d}t\nonumber\\ % &\leq \frac{4}{2N+3}. \end{align}\]
